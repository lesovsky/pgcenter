## Оговорка по критерию 6

Экраны `pg_stat_statements` (`x`, `X`) на этом стенде не проверены: расширение не установлено
(`shared_preload_libraries = pgpro_scheduler, pg_query_state, pg_wait_sampling, pgpro_stats`).
Механизм при этом подтверждён — программа сообщает и **сохраняет паузу**, что и требует спецификация
для действия, которое не состоялось:

```
[PAUSED] NOTICE: pg_stat_statements not found
[PAUSED] NOTICE: pg_stat_statements is not available in this database
```

Маркер и сообщение сосуществуют в одной строке — композитор cmdline не затирает маркер.

## Два случая, которые сначала выглядели дефектами

1. **`,` не снимает паузу на экране `activity`.** Причина не в фиче: `toggleSysTables`
   (`top/config_view.go:430-432`) выходит сразу, если экран не `tables`/`indexes`/`sizes`, — и так
   было до 016. Снятие паузы стоит **ниже** этого возврата, то есть ровно по спецификации: действие
   без эффекта оставляет заморозку. На экране `tables` клавиша паузу снимает — проверено отдельно.

2. **`A` не снимала паузу.** Артефакт прогона: диалог требует формат `HH:MM:SS`, а был введён `30`.
   С корректным `00:00:30` пауза снимается.

## Наблюдение (не критерий, не дефект)

Строка cmdline не перерисовывается сама по себе при изменении размера терминала: до следующей записи
в неё остаётся прежний текст, обрезанный терминалом (`[PAUSED][F:datna`). После любого события,
пишущего в cmdline, лестница токенов отрабатывает корректно. Перерисовка **кадра** при ресайзе
(критерий 13) работает — это касается только строки cmdline.

## Сравнение с master (шаг 10)

Чистое A/B на свежезапущенных экземплярах: заголовки таблицы идентичны, верхние панели структурно
идентичны, cmdline у обоих пуст в живом режиме. Различия ровно два, оба — сама фича:
`[PAUSED]` с заморозкой по `Space` и двухстрочная запись в справке (38 против 35 непустых строк).
Дрейфа раскладки фича не вносит.
